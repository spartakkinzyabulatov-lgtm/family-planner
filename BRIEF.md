# Семейный план

## Задача
Общий список семейных покупок и расходов, чтобы не держать планы в голове.
План согласован Спартаком 25.11.2026: «да газ».

## Кто пользуется
Семья по одной ссылке, преимущественно с телефона.

## Первая версия
- Покупка: название, сумма в рублях (может быть неизвестна), дата (может быть не выбрана), категория, комментарий.
- Добавление и редактирование, отметка «Куплено / оплачено», возврат в планы.
- Разделы «Предстоящие» и «Закрытые», фильтр по месяцу, поиск, сумма предстоящих расходов.
- Проверка общего PIN на сервере; PIN не входит в публичный код.
- Телефон хранит зашифрованную копию. После первого входа можно открыть приложение и вносить изменения без сети.
- Изменения синхронизируются при открытом приложении и восстановлении связи. Офлайн-изменения не теряются при перезагрузке.
- Изменения отдельных полей объединяются; если двое изменили одно поле, побеждает последняя принятая сервером правка.
- PWA: установка на главный экран и офлайн после первого открытия.

## Экраны
Вход; общий список со сводкой; форма покупки; настройки с установкой, ручной синхронизацией и блокировкой.

## Данные и ограничения
Публичный GitHub содержит только код. Настоящие семейные записи, PIN и сеансы в Git не попадают.
Сервер: Python (стандартная библиотека), SQLite, отдельный системный пользователь, HTTPS через Caddy.
Телефон: AES-GCM и PBKDF2; ключ выводится из введённого PIN и остаётся только в памяти.
Без сети доступна последняя загруженная копия; обновления других членов семьи приходят при восстановлении связи.
Первый вход на новом устройстве требует интернета. Короткий семейный PIN ограничивает уровень защиты.
Нет удаления покупок, банковских интеграций, оплаты, уведомлений и учёта доходов.
По отдельной просьбе подготовлен импорт 18 незакрытых пунктов со скриншота: ноябрь 2026, декабрь 2026, январь 2027. Импорт зашифрован и хранится вне проекта; личные записи в публичный код не входят. Диапазоны цен записаны заметками; точная дата задана только там, где указана в исходнике.

## Готово, когда
Проверены вход, сумма/дата, редактирование, галочка и возврат; два независимых устройства видят обновления; офлайн-запись переживает перезагрузку и уходит на сервер при восстановлении сети; на ширине 375px нет прокрутки вбок; в консоли нет ошибок.
