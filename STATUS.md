## Решения
- При одновременном изменении одного поля побеждает последняя принятая сервером правка; отдельные поля объединяются.
- Для надёжной работы нескольких вкладок требуется современный браузер с Web Locks и Web Crypto.
- Диапазоны расходов не заменены выдуманной точной суммой и не включены в итог известных сумм.
- Установщик предназначен для первого запуска, отказывается перезаписывать существующие пути.
